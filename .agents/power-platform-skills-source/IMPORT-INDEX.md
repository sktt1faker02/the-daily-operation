## Compatibility notes

- Codex discovery entries live in `.agents/skills/<skill-name>/SKILL.md`. Each entry routes to the complete canonical Microsoft instructions.
- The original Power Platform Skills repository and all plugin-local/shared resources are retained under `plugins/`, `shared/`, and `evals/`; the external Dataverse repository paths and plugin resources are retained under `dataverse/`.
- Original plugin manifests, agents, scripts, examples, references, templates, and license/attribution files are preserved. Git metadata, repository CI, and installers are not copied because they are not runtime skill resources. Referenced evaluation guides, scripts, examples, templates, documentation, and plugin resources are retained.
- Claude/Copilot plugin manifests, agent personas, commands, allowed-tool lists, and MCP servers are not Codex integrations. Written workflows are adapted through the discovery entries; an unavailable tool is never claimed or invoked.
- Source includes capabilities for unrelated Power Platform areas. Use them only when the task matches; do not let them supersede project business/security rules.
- External Dataverse source: `https://github.com/microsoft/Dataverse-skills`, plugin path `.github/plugins/dataverse`.
